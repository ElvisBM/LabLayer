# Required Mercado Livre category attributes

Loads each selected category's official required attributes and displays them by their human-readable names in the ad review form. Missing required values prevent approval; the values are saved in the draft attributes sent to Mercado Livre. For category MLB117803 this shows Fabricante and Marca.

Validation errors for missing required attributes now identify the field and where to fill it. The release also includes the net payout calculator and its styles. It replaces only the existing drafts API module, the existing Marketplace Listings bundle, and the global stylesheet in place; it preserves the active index, React/App and assistant bundles.
